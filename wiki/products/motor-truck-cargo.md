# Motor Truck Cargo (MTC)

Motor Truck Cargo (MTC) is a commercial inland marine product covering loss of or damage to freight and cargo transported by motor carriers. It is written on an open perils or named perils basis under the base form IM 7450. Coverage attaches when cargo is in the care, custody, and control of the insured trucker.

This is a commercial product line — it is not related to personal automobile insurance. Key rating variables include commodity class, operating radius, vehicle fleet characteristics, use of owner-operators, and insured financial size (gross receipts or number of power units).

## Coverage Parts

| Coverage | Description |
|---|---|
| Cargo (Per Vehicle basis) | Loss of or damage to cargo; rated per power unit and vehicle limit |
| Cargo (Gross Receipts basis) | Same cargo coverage rated on gross receipts for larger fleets |
| Refrigeration Breakdown | Optional; covers cargo spoilage from refrigeration failure |
| Contingent Cargo | Optional; covers cargo in care of subcontractors |
| Named Perils | Optional narrowing endorsement (IM 7488); reduces open perils to named perils |
| Mobile/Moving Equipment | Optional; covers mobile equipment, moving equipment (IM 7450 built-in $5,000 sublimit) |
| Electronic Equipment | Optional; on-board and off-board electronics (IM 7450 built-in $5,000 sublimit) |
| Personal Property | Optional add-on under IM 7450 |
| Trailer Coverage | Optional; covers physical loss to trailers |
| Adulterated Food | Optional; refer to company for rating |

## Rating Method Selection

Two primary rating methods are defined by insured size:

- **Per Vehicle (Method A):** Gross receipts ≤ $500,000 or fewer than 10 power units
- **Gross Receipts (Method B):** Gross receipts > $500,000 or 10+ power units

## Key Rating Variables

- **Commodity Classification (1–5):** Determines base load tier; Class 5 is target/hazardous cargo requiring additional modification
- **Operating Radius:** Local (≤50 mi), Intermediate (51–200 mi), Long Haul (>200 mi)
- **Vehicle Protection:** Guards/escort; alarms/tracking; none
- **Owner-Operator Use:** None; limited (with checks); extensive (limited supervision)
- **Fleet Condition:** Newer/documented; mixed/irregular; older/poor documentation
- **Financial Stability:** Excellent, Good, Poor (via financial statement or CAB report)

## Forms Referenced

IM 7450 — Base MTC coverage form (includes built-in sublimits for moving equipment and electronics)
IM 7488 — Named Perils Endorsement (applies 0.90 modification)
