## AK Coverage Options

[multistate, unchanged] — All coverage options, rating methods, commodity classification, and reporting form rules from the multistate base apply in Alaska without modification.

See [multistate/motor-truck-cargo/rating-rules/coverage-options.md](../../../multistate/motor-truck-cargo/rating-rules/coverage-options.md) for full detail.

### Summary of Available Coverages

| Coverage | Rating Method | Notes |
|---|---|---|
| Cargo — Per Vehicle | Method A | For gross receipts ≤ $500K or fewer than 10 power units |
| Cargo — Gross Receipts | Method B | For gross receipts > $500K or 10+ power units |
| Refrigeration Breakdown | Added to A or B | Optional |
| Contingent Cargo | Modification to A or B | Optional |
| Mobile/Moving Equipment | Method C | Optional |
| Electronic Equipment (Off/On-Board) | Method C | Optional |
| Personal Property | Method C | Optional |
| Trailer Coverage | Method D | Optional |
| Adulterated Food | Refer to Company | Optional |

### Commodity Classification

Classes 1–5 apply as published in the multistate manual.
Class 5 (target/hazardous cargo) requires a separate modification (1.25–2.00).
